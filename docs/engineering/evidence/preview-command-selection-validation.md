# T03/T07/T11 预览命令与自动节选

`preparePreview` 仅代表显式预览授权，冻结 brief、Understanding 引用、consent、revision/preview/operation ID。owner、版本、输入待处理、并发聊天或制作占用均会阻止队列派发；同命令重放保留编号，队列故障只补派发。未创建正式制作批准。重复请求与 Worker 已 claim 的竞争回归先失败，修复为只比较不可变操作输入。

`selectPreviewExcerpt` 选择实际冻结视频区间，优先镜头声明的关键事实，最终 6–12 秒、最多五段，精确映射整数毫秒和视频帧。旁白采样及字幕帧可形成分数毫秒边界，不向内舍入；窗口任何部分被截断都拒绝。镜头声明含某事实不等于画面已正确显示，该项仍需真实视觉检查。

测试首先因目标模块缺失失败。两项独立审查进一步复现：分数时间被旧 validator 拒绝、超过五段、仅首中尾搜索漏安全整句、五个极短关键镜头导致贪心卡死，以及遗漏可组合的小于六秒安全片段。分别补精确失败用例后修复；有界候选与动态组合搜索保留完整句子和字幕窗口，不补写语音或插入占位画面。
