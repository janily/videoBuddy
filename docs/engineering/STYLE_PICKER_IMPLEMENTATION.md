# 画风选择交互实现与验收

实现依据：`docs/product/style-picker-ux.md` v1.0；基线 main `c729963`。本次只调整画风选择和必要的偏好保存边界。

## 实现

- 欢迎页固定六张代表封面；点样片只打开并定位画风库，不选中、不发送聊天消息。样片区位于示例按钮下方。
- 统一 StyleTile 用于推荐、二级画风库和独立 `/video/styles`。推荐理由来自助手；窄画布推荐采用单列横排。
- 画风库复用 `.work` 唯一纵向滚动，内容自然换行；不透明吸顶头部包含搜索、分类和读屏计数。搜索覆盖中英文、ID、用途、气质和关键词，150 ms 防抖。
- history 记录二级视图；支持返回按钮、Esc、后退、前进和刷新恢复。退出时恢复滚动和入口焦点，普通助手画布链接也能退出库并定位目标。
- 选择成功后显示五秒撤销提示。首次项目先创建再直接保存偏好，助手确认与偏好更新原子提交；撤销绑定保存回执版本，不能覆盖另一标签页后来的更新。已有脚本/成片时先原地确认；取消不发偏好变更。
- 欢迎页的打开/搜索/筛选埋点先保存在有界内存中，创建项目后补报；搜索只记录长度和结果数。首次选择使用保存回执的项目 ID，记录推荐位置与来源。
- 43 张同主题咖啡封面、43 份可复现 HTML 和生成/验证脚本已入库。swatch 与清单同源。首屏封面预算为 12 张，后续按可见性及用户滚动加载。
