# 极简出片流程（quick）

当前唯一出片路径。用户聊清楚主题、选好画风后点“生成视频”，一次得到完整视频；不满意就在聊天里改，或者只换配乐、只重画某一镜。

## 五步

| 步骤 | 做什么 | 模型调用 |
|---|---|---|
| 1 构思 | 按画风规则写故事和镜头表 | 1 次 |
| 2 画镜头 | 每个镜头写一份 HTML/Canvas 源码，后面的镜头以第一镜为参照保持角色和画风一致 | 每镜 1 次（源码不合格时最多再修正 1 次） |
| 3 渲染 | 本地沙箱 Chromium 逐帧渲染，FFmpeg 编码并叠加 AI生成标识 | 0 |
| 4 拼接 | FFmpeg concat demuxer 按镜头表拼接，视频流复制 | 0 |
| 5 配乐与标识 | 从曲库选曲（循环、淡入淡出、响度统一到 -16 LUFS），视频流不重新编码，文件元数据写入 AIGC 标识 | 0 |

代码：`src/services/video/quick/`（film.ts 是五步本身，operation.ts 负责任务生命周期和发布）。

每一步的结果都按输入缓存（`projects/<id>/quick/b<版本>/…`、`media/<stageKey>`、`media/assembly/<key>`），所以：

- **换配乐**：只重做拼接与配乐，不重新编码视频流。
- **重画某一镜**：只重做这一镜的第 2、3 步，再做第 4、5 步。
- **聊天改了内容**：想法版本变了，从第 1 步重新来。

不再经过：旁白合成、语音识别核验、Audio 模型、预览片段、批准、两轮内容审查、整片 Critic。保留：画面源码静态安全检查、确定性渲染检查（同一帧渲染两次必须一致）、成片技术检查（解码、尺寸、时长、帧率、音轨）。

## 曲库

`VIDEO_MUSIC_DIR` 指向一个绝对路径目录（路径里不要有空格），里面放音频文件和 `library.json`：

```json
{
  "schemaVersion": 1,
  "tracks": [
    {
      "id": "moon-reunion",
      "title": "月下团圆",
      "file": "moon-reunion.mp3",
      "durationSec": 96,
      "moods": ["温暖", "安静"],
      "styles": ["paper-lantern", "ink-wash", "papercut-red"],
      "license": "CC BY 4.0 · 作者名",
      "source": "https://…",
      "sha256": "文件的 sha256"
    }
  ]
}
```

- 只放你有权在产品里分发的音乐（自有版权、CC0，或购买了可商用授权的曲库）。`license` 会显示在视频下方。
- `styles` 写适合的画风 id，`moods` 写情绪词。自动选曲时，画风匹配权重最高，其次是情绪与画风情绪、用户主题的匹配。
- 计算 sha256：`sha256sum moon-reunion.mp3`。服务启动后修改文件，选曲时会因哈希不一致报错，避免悄悄换了曲子。
- 曲子短于视频时会循环，末尾 2.5 秒淡出。

## 画风样片

把每种画风的样片截图放在 `public/style-samples/<画风id>.jpg`，画风弹窗和画风页会自动显示，见该目录 README。
