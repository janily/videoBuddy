# Self-hosted migration and completion plan

当前研发优先级以 [MVP优先计划](MVP_FIRST.md) 为准（用户2026-10-05最新指示）：先接通正式确认、结果发布、下载和一次修改。下文图片接线等历史“下一步”暂移后续，不再作为MVP前置。

Execution is authorized by the user's 2026-10-02 instruction to redesign and build the complete project without Vercel. This plan changes infrastructure while retaining the v5.1 product and acceptance scope. Every implementation task uses a failing behavior test first and records actual results; no missing external service is marked passed.

1. **Replace platform storage.** Promote the file adapter to production with cross-process locking, crash repair rules, fsync and path checks. Move `productionStore`, app configuration and probes to `VIDEO_DATA_DIR`. Exercise two cold processes against the same volume. Preserve anonymous scopes and immutable refs.
2. **Replace Workflow SDK.** Add a durable operation queue, worker entry point, stage ledger, startup reconciliation and terminal states. The message route only commits input and enqueues. The worker runs Director/other stages. Keep original command ID and canonical claim invariants; classify unknown paid effects rather than rerunning them. Remove `workflow` and build integration only after the replacement has passed restart tests.
3. **Replace stream transport.** Append bounded events to durable per-operation logs. SSE replays cursors, follows new records and reconciles to archived messages after log loss. Verify UTF-8/CRLF, gaps, epoch reset, disconnect and cold restart.
4. **Replace media execution.** Build and pin a Docker image with Chromium, FFmpeg, fonts, the trusted runner and declared licenses. Implement detached run, inspect, stop and actual output probe with fixed resource flags and no network. Keep `MediaExecutor` boundary. Verify generated source never executes in web/worker host.
5. **Complete sources and models.** Implement real private uploads, MIME/byte probe, PDF/image/audio analysis with source refs, then Director/Visual/Audio/Critic outputs with strict schemas, budgets and one durable effect per external call. Evaluate 16 behavior cases.
6. **Complete preview and delivery.** TTS/ASR and full timeline; real composite preview; exact preview approval; render, independent QA and atomic publish; safe changes, cancellation, restoration, playback, signed download, subtitles and export; resource cleanup. Test the vertical path with a new theme, Chinese narration and a silent English case.
7. **Complete styles and release.** Adapt each of the 43 rules to real generated content; render horizontal and vertical new-theme media, check 3D/GL profiles, store 86 real evidence records. Run responsive and accessibility tests, five-user observation, backup/restore, security, budget and rollback drills. Package a Linux self-host deployment and only call C2 complete after the full acceptance matrix passes.

Review focus: (a) local lock crash and multi-process CAS, (b) unknown external charges on worker restart, (c) event log durability and cursor mapping, (d) container isolation and output symlinks, (e) user approval fence across message/archive/render CAS, (f) all 43 styles genuinely adapted rather than directory-only inventory. The earlier Vercel-specific task ledger remains historical; this plan supersedes its deployment tasks.
